# The six-act house arc

The default house shape. A build-to-verdict variant: state the headline, then earn it by drilling into one
concrete example and rolling back up to the same number. Use it when the method is part of the sell.

## The acts

1. **Hook** (1-2 beats) — a centered title card, then the single biggest number or claim. The reader now
   has the "what" but not the "how"; that tension pulls them down the page.
2. **The landscape / tour** (several beats) — walk the space one segment at a time (per territory, per
   format, per category). Each beat: one subject, one map scene, a stat chip row. End with a synthesis or
   ranking beat that closes the tour and sharpens the open question.
3. **The pivot** (1 beat) — a centered interstitial ("How we measure this"). A full stop that shifts
   register from conclusions to evidence. Usually no map, a photo or plain backdrop.
4. **The methodology engine** (the heart, many beats) — drill into ONE real, named, grounded example and
   advance through the pipeline step by step, each step a live map scene: map the universe → fence one unit
   → observe real signals → trace movement → resolve origins → add the value layer. Concreteness (a real
   unit, a real time, a real place) is what makes the method believable.
5. **Aggregation** (a few beats) — telescope back out: unit → area → region, the numbers rolling up until
   they equal the opening claim. This closes the loop and converts method into the headline figure.
6. **Close** (1-2 beats) — return to an interactive or overview state, then a centered outro that mirrors
   the intro lockup and echoes the opening language for resolution.

## Beat skeleton (fill per project)

```
intro     [Hook]        centered title
exec      [Hook]        the headline number
tour-01   [Tour]        segment 1 profile + chips
tour-02   [Tour]        segment 2 profile + chips
...
tour-rank [Tour]        the ranking/synthesis that closes the tour
pivot     [Pivot]       "how we measure this", no map
m-universe[Method]      map the whole universe of units
m-fence   [Method]      fence one named unit
m-signal  [Method]      observe its real signals
m-trace   [Method]      trace movement to it
m-origin  [Method]      resolve where demand comes from
m-value   [Method]      add the money / outcome layer
agg-unit  [Aggregation] one unit's number
agg-area  [Aggregation] roll up to the area
agg-region[Aggregation] roll up to the region == the hook number
outro     [Close]       mirror the intro
```

## Signature move

The hook beat and the final aggregation beat state the **same** headline chips. The reader saw the number
claimed at the top and now sees it proven at the bottom. That mirror is the whole point of the arc; if the
close does not land the exact opening number, the arc has not closed.
