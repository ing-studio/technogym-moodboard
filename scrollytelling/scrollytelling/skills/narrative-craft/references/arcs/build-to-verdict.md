# Build-to-verdict arc

Use when the finding is counterintuitive, or the audience is skeptical, or the *method* is what earns
belief. Withhold the verdict, walk the evidence in order, and let the reader arrive at the conclusion so it
feels earned rather than asserted. The six-act house arc is a fully worked instance of this shape.

## Shape

1. **Tension** (1-2 beats) — the open question or the surprising gap, stated so the reader wants the
   answer. Name the number that is at stake without yet resolving it.
2. **Ground rules** (1-2 beats) — what the evidence is and how it is read, so no one disputes the basis
   later. Brief, honest about grade.
3. **The walk** (many beats) — the evidence in sequence, each beat one step, each visibly built on the
   last. This is the longest act; it is where trust is won. One idea, one scene per beat.
4. **The turn** (1 beat) — the moment the accumulated evidence forces the conclusion. The pivot of the
   whole deck. State it plainly; the walk has done the persuading.
5. **Verdict + bounds** (1-2 beats) — the answer, now earned, plus where it is soft.
6. **Close** (1 beat) — mirror the opening tension: the question from beat one, now answered in the same
   words.

## Beat skeleton

```
tension    the open question / surprising gap
basis      what the evidence is, how it is read
walk-01    evidence step 1
walk-02    evidence step 2 (builds on 01)
...
walk-0N    evidence step N
turn       the moment the evidence forces the conclusion
verdict    the answer, earned + bounds
close      the beat-one question, now answered verbatim
```

## The risk to watch

A build-to-verdict deck that walks too long loses a busy reader before the turn. If the audience is
time-constrained, switch to answer-first. Withholding the verdict is only worth it when the reader will
actually stay for the walk.
