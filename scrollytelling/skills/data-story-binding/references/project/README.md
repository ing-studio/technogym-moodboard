# project slot — data-story-binding

Delegated place for a specific project's data files. The skill's `SKILL.md` and the other `references/`
files stay project-agnostic; anything naming a real source, sheet, or figure lives here.

Drop here, as needed:
- the source workbook(s) / geojson the deck draws from (or a pointer to their path).
- the generated `profile.yaml` for this project's data folder.
- the `contract.yaml` mapping every on-screen number to its source, grade, and invariant.

Nothing in this folder is loaded automatically. Generated by `scripts/profile.py` or authored per
project; read only when a task points at this project.
