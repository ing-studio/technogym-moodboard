# project slot — scrollytelling

Delegated place for a specific project's artifact files. The skill's `SKILL.md` and the other
`references/` files stay project-agnostic; anything naming a real client, community, or dataset lives
here.

Drop here, as needed:
- the project's real deck HTML, to fork instead of `engine_skeleton.html` (it carries live data wiring).
- brand assets (logos, lockups) as base64 or files.
- a base map style override, if the project departs from dark-matter.

Nothing in this folder is loaded automatically. The agent or author reads it only when a task points at
this project. Keep it out of the generic instructions.
