# project slot — narrative-craft

Delegated place for a specific project's story inputs. The skill's `SKILL.md` and the other `references/`
files stay project-agnostic; anything naming a real client, place, or figure lives here.

Drop here, as needed:
- the pre-flight brief (the controlling question, the decision it informs, the audience posture).
- the chosen arc for this deck (answer-first or build-to-verdict) and why.
- an on-screen glossary: the terms allowed on screen, and internal codenames banned from it.
- a banned-figure list: numbers that must never appear.

Nothing in this folder is loaded automatically. Read only when a task points at this project.
